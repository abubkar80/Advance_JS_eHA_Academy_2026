
# JavaScript Personal Profile Challenge

## Description
A simple JavaScript program that stores personal
information in an object.

## Concepts Demonstrated
- JavaScript Objects
- Strings, Numbers and Arrays
- Date Objects
- Functions
- Comments
- Console Output

## How to Run

1. Install Node.js.
2. Clone this repository.
3. Open the project folder.
4. Run:

   node profile.js
