# eHA Academy – Advanced JavaScript 2026

This repository contains practical exercises, assignments, assessments, and learning projects completed as part of the **eHA Academy Advanced JavaScript 2026** programme.

The repository documents my learning journey through JavaScript fundamentals, asynchronous programming, DOM manipulation, and interactive web development.

## Repository Contents

### 1. Callback Assignment

**Location:** `tasks/callback-assignment/`

Demonstrates JavaScript callback functions and asynchronous execution using `setTimeout()`.

**Concepts covered:**
- Callback functions
- Asynchronous JavaScript
- Error handling with `try...catch`
- Delayed execution using `setTimeout()`

**How to run:**
```bash
node tasks/callback-assignment/fetchDataCallback.js
```

The current example simulates a failed data-fetch operation and displays an error message.

### 2. Personal Profile Assignment

**Location:** `tasks/Personal-Profile-Assignment/`

Demonstrates how to create and work with JavaScript objects and functions to represent personal profile information.

**Concepts covered:**
- JavaScript objects
- Object properties
- Functions
- Arrays
- Date objects
- Console output

**How to run:**
```bash
node tasks/Personal-Profile-Assignment/profile.js
```

### 3. Interactive To-Do List

**Location:** `tasks/todo-interactive/`

A simple interactive To-Do List built with HTML, CSS, and JavaScript. Users can click tasks to mark them as completed or undo their completion.

**Concepts covered:**
- DOM manipulation
- Selecting HTML elements
- Event listeners
- `forEach()`
- `classList.toggle()`
- CSS classes and styling

**How to run:**

Open `tasks/todo-interactive/index.html` in a web browser.

No additional packages are required.
